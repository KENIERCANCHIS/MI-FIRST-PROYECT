# MI-FIRST-PROYECT — Resumen del repositorio

Este documento resume el repositorio `MI-FIRST-PROYECT` para usarlo como
fuente en NotebookLM.

## Qué es

`MI-FIRST-PROYECT` es el primer proyecto en GitHub de su autor, Kenier
Canchis. Es un repositorio de práctica: en este momento su contenido
principal es un README de presentación y, como parte de este ejercicio,
una skill de Claude Code para integrarse con NotebookLM.

## Estado actual

- El repositorio contiene un único archivo de documentación (`README.md`)
  con el título del proyecto y una breve descripción ("This is my first
  proyect").
- Se añadió una skill personalizada de Claude Code
  (`.claude/skills/notebook-lm/SKILL.md`) que define un flujo de trabajo
  para preparar contenido del repo como fuentes para NotebookLM, y para
  traer de vuelta notas generadas en NotebookLM hacia el proyecto.
- No hay código de aplicación, dependencias ni pruebas todavía: es un
  proyecto en su etapa inicial.

## Por qué existe este documento

Sirve como ejemplo de cómo la skill "notebook-lm" convierte contenido de
un repositorio en un texto legible y bien estructurado, listo para que una
persona lo suba manualmente a NotebookLM y genere resúmenes, preguntas y
respuestas, o un Audio Overview a partir de él.
