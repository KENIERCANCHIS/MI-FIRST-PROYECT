# Contexto del proyecto

Claude Code lee este archivo automáticamente al iniciar una sesión en este
repositorio. Sirve como "memoria" persistente: lo que escribas aquí no hay
que repetirlo en el chat, lo que ahorra tokens.

## Cómo usarlo con tus notebooks de NotebookLM

1. Abre el notebook en notebooklm.google.com.
2. Copia el resumen, las notas clave o las respuestas que te interesa que
   Claude recuerde.
3. Pégalas debajo, en la sección "Notas de mis cuadernos", en tus propias
   palabras o tal cual las copiaste.
4. Guarda el archivo. Listo — la próxima sesión ya parte con ese contexto.

No hace falta código ni automatización para esto.
